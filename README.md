# Chzzk Plays Tekken

치지직 채팅으로 철권 캐릭터를 조종하는 방송용 봇입니다. 시청자가 채팅에 명령을 치면 봇이 키보드 입력으로 바꿔 게임에 보냅니다. OBS 브라우저 오버레이로 누가 어떤 명령을 쳤는지 방송 화면에 보여줍니다.

> 치지직 **공식 API**를 사용합니다. Client ID와 Secret은 비어 있으니 직접 발급받아 넣어야 합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `chzzk_plays_tekken_official.py` | 봇 본체 (공식 API) |
| `overlay.html` | OBS 브라우저 소스용 오버레이 (봇과 같은 폴더에 둠) |
| `run.bat` | 필요한 패키지 설치 후 봇 실행 (Windows) |

## 준비

1. [치지직 개발자 센터](https://developers.chzzk.naver.com)에서 애플리케이션 등록
   - 로그인 리디렉션 URL: `http://localhost:8080/callback`
   - API Scope: **채팅 메시지 조회**
2. `chzzk_plays_tekken_official.py`를 메모장으로 열어 `CLIENT_ID`, `CLIENT_SECRET`에 발급받은 값 입력
3. 같은 파일의 [설정]에서 철권 키 배치(기본 WASD / U I J K)와 `MY_SIDE`(오른쪽=2P, 왼쪽=1P) 확인
4. Windows + Python 3.10 이상. `run.bat` 더블클릭 → 브라우저에서 치지직 로그인·동의 → 철권 창 클릭해 활성화

Python 3.15처럼 아주 최신 버전에서는 chzzkpy가 고정한 옛 부품이 설치되지 않아서, `run.bat`은 chzzkpy를 의존성 없이 설치한 뒤 최신 부품을 따로 설치합니다.

## 채팅 명령

| 종류 | 예시 | 동작 |
| --- | --- | --- |
| 방향 | `6` `4` `2` `3`, `앞` `뒤` `앉아` `점프`, `앞대각` `뒷대각` `윗대각` | 숫자패드 표기, 캐릭터가 보는 방향 기준 |
| 버튼 | `1` `2` `3` `4`, `lp` `rp` `lk` `rk`, `1+2`, `ap` | `+`로 이으면 동시 |
| 방향+버튼 | `앞대각4`, `3rk`, `6+1`, `앞1+2` | 방향과 버튼 동시 |
| 차례 버튼 | `lklprp` | 붙여 쓰면 하나씩 차례로 |
| 커맨드 | `6n23rp`, `236lp`, `6n23n6n23rp` | 방향 순서대로, 마지막 방향과 버튼 동시 |
| 특수 | `잡기` `대시` `백대시` `연속백대시` | 연속백대시 = 4414 414 414 414 414 |
| 사이드 | `사이드변경` `왼쪽사이드` `오른쪽사이드` | 좌우 전환 (3초 쿨타임) |

규칙: `+` 앞 숫자는 방향, 뒤 숫자는 버튼. 한글 방향 뒤 숫자는 버튼. 붙여 쓴 숫자는 방향 커맨드(`12` = ↙↓). ↘+4는 `3+4`(양발)가 아니라 `앞대각4` 또는 `3rk`.

## 모드와 설정

- `MODE = "혼돈"`: 채팅 오는 대로 실행 / `"민주주의"`: 3초 동안 투표해 1등만 실행
- 같은 닉네임은 1초에 1번, 대기열 10개 초과분은 버림
- 타이밍 조절: `STEP`, `CHAIN_HOLD`, `BUTTON_GAP`, `COMMAND_GAP`, `BACKDASH_STEP`

## OBS 오버레이

봇을 켜면 오버레이 서버(포트 8765)가 함께 켜집니다.

- 원컴: OBS 브라우저 소스 URL `http://127.0.0.1:8765`, 1920×1080
- 투컴: 봇은 게임 PC에서 실행하고, 송출 PC OBS에 봇 창에 표시되는 `http://(게임PC IP):8765` 입력. 게임 PC 방화벽에서 Python의 개인 네트워크 허용
- 위치·크기: `?pos=bc|bl|br|tl|tr&scale=1&max=5&hold=6` (기본 가운데 아래)

## 주의

- 키 입력은 봇이 실행 중인 PC의 활성 창으로 들어갑니다. 방송 중 다른 창을 클릭하면 그 창에 입력됩니다.
- 경기 중 캐릭터 좌우가 바뀌어도 봇은 알 수 없으니 `사이드변경`으로 맞춥니다.
- Client Secret은 비밀번호와 같습니다. 값을 넣은 파일은 공유하지 마세요.
- 종료: 봇 창에서 Ctrl+C
